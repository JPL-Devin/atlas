# Mission card images

All source images come from the [NASA Photojournal](https://science.nasa.gov/photojournal/galleries/). The
canonical image pages, PIA IDs, and credit lines are listed in [the homepage configuration](../../../src/config/home/index.js).
The WebP files are resized and cropped to 800 × 450 for the landing page cards.

`juno-jovian-storms-pia25691.webp`: [NASA’s Juno Mission Captures Swirls in Jovian Storms](https://science.nasa.gov/photojournal/nasas-juno-mission-captures-swirls-in-jovian-storms/).
Image data: NASA/JPL-Caltech/SwRI/MSSS; image processing: Kevin M. Gill, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
