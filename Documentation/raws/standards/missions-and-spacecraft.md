# Missions and Spacecraft

Use lowercase mission and spacecraft names in [file URIs](../api/uri).

| Mission | Spacecraft |
| --- | --- |
| `m20` | `perseverance`, `ingenuity` |
| `msl` | `curiosity` |
| `insight` | `insight` |
| `cassini` | `cassini` |
| `psyche` | `psyche` |
