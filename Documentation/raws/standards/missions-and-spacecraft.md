# Missions and Spacecraft

Use lowercase mission and spacecraft names in [file URIs](../api/uri).

| Mission | Spacecraft | Feeds |
| --- | --- | --- |
| `m20` | `perseverance`, `ingenuity` | `main` |
| `msl` | `curiosity` | `msss`, `mslice`, `mosaics` |
| `insight` | `insight` | `main` |
| `cassini` | `cassini` | `main` |
| `psyche` | `psyche` | `main` |

Feeds identify source streams within a mission, written as `mission/feed`
(for example, `msl/mslice`). They are not spacecraft names in file URIs.
